  • docx:document — 读取与编辑文档
    • 
              
  • docx:document.block:convert — Markdown 转换
    • 
              
  • wiki:wiki:readonly — 读取知识库
    • 
              
  • drive:drive:readonly — 读取云空间与图片
    • 
              
  • board:whiteboard:node:read — 读取画板
    • 
              
  • board:whiteboard:node:create — 编辑画板
